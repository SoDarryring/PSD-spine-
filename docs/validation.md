# 验证范围

2026-11-06 开源首版在 Windows 上通过 21 项常规检查和 3 项真实 Photoshop / Spine 集成检查，测试环境为 Python 3.14.3、Photoshop 2026、Spine 3.8.99。便携版通过内置资源与原生拖放库初始化检查。具体边界见本页末尾。

## 常规检查

运行 `python -m unittest discover -s tests -t . -v`，无需安装或启动 Photoshop / Spine。

| 范围 | 检查内容 |
| --- | --- |
| 输出管理 | 成功结果只含指定格式和图片；默认在 PSD 旁；不覆盖同名目录 |
| 失败恢复 | 清理临时副本，不触碰已有结果和输入文件 |
| 数据验证 | 图片引用、目录边界、空数据、JSON 尾随逗号修复 |
| 官方脚本适配 | 固定版本指纹、中文路径、入口与原点设置 |
| Spine 调用 | 精确使用 3.8.99；退出码及非空工程文件检查 |
| GUI | 多种屏幕 / DPI 的启动尺寸；TkDnD 注册与中文多文件回调 |

## 实际 Photoshop / Spine 检查

设置 `PSD_SPINE_INTEGRATION=1` 后运行 `python -m unittest tests.test_integration_photoshop -v`。此流程会启动 Photoshop；测试前请保存自己的工作，并让 Photoshop 空闲。

测试在临时目录生成合成 PSD：400×300 画布、中文图层、嵌套骨骼组和隐藏定位图层。定位图层位于底部嵌套分组，内容边界中心为 `(120,230)`。开启原点选项后，身体附件应位于 `(80,40)`，head 骨骼应位于 `(65,135)`；50% 缩放时身体附件应位于 `(40,20)`。

检查还包括原点切换前后的 PNG 像素一致、源 PSD 指纹不变，以及通过真实 Spine 3.8.99 重新读取 `.spine` 并导出 JSON。测试只使用自动生成的色块，不包含用户美术资源或商业软件。

## 便携版检查

构建脚本会运行 `PSD一键转Spine.exe --self-check`，验证解包后的官方插件指纹、CustomTkinter、原生 TkDnD 库、中文文件回调及默认输出设置。构建报告留在忽略版本控制的工作目录，不加入工程输出。

## 验证边界

- TkDnD 回调和原生库加载检查不等于资源管理器物理拖放的端到端验证；不同权限、桌面会话和系统环境仍需人工测试。
- 屏幕尺寸计算覆盖多种 DPI；跨不同 DPI 显示器移动窗口未做全面人工回归。
- 复杂图层样式、调整层、智能对象、遮罩、特殊混合及巨型 PSB 未逐种验证，沿用官方脚本支持范围。
- 合成样例覆盖图层摆放和工程导入；不验证用户 PSD 的完整视觉一致性，也不包含自动骨骼绑定或动作制作。
- CI 的实际 Photoshop / Spine 检查默认跳过，不能据此判断这两个商业应用的集成在任意机器均可用。
