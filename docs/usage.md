# 使用说明

## 单文件版

v1.1.1 起只需下载并运行一个 EXE，可以单独复制到其他位置或电脑。不另附使用说明或许可文件夹；必要的许可原文已内置，在右上角“关于”中查看。

本机仍需要可正常运行的 Photoshop；生成 `.spine` 还需要已激活并能运行 3.8.99 的 Spine。单文件打包不包含这两个商业软件。

## 选择源文件和保存位置

可以点击“添加文件”，也可以把多个 PSD / PSB 拖进窗口。拖入文件夹时只扫描这一层，不递归扫描其子目录。文件会自动去重，可以点击每行的 × 移除。

默认在每个 PSD 旁边创建同名工程文件夹；同名目录已存在时追加 `_2`、`_3` 等编号。也可以切换到“自定义目录”。每次启动默认恢复为“PSD 所在目录”。

工程模式成功后只保留 `.spine` 和 `images/`，图片使用相对引用，可以把整个工程文件夹移动到其他地方。勾选“仅导出 JSON 和图片”后，则保留 `.json` 和 `images/`，不生成 `.spine`。

## 调整转换选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| 图层缩放 | 100% | 大于 0 且不超过 400% |
| 图片留边 | 1 像素 | 在独立图片周围保留透明采样边界，最大 256 |
| 跳过隐藏图层 | 开启 | 不导出隐藏层；需要隐藏的换装层时关闭 |
| 跳过背景图层 | 开启 | 不导出 Photoshop 的正式“背景”层 |
| 裁剪透明边 | 开启 | 缩小独立 PNG 的透明空白区域 |
| 最底层图层中心作为 Spine 原点 | 关闭 | 开启后覆盖本次副本的标尺原点 |
| 仅导出 JSON 和图片 | 关闭 | 无需 Spine，输出可供后续导入的数据 |

中心点取图层面板最底部的实际图层。如果底部是分组，会继续递归取组内最底层；隐藏的图层也可以用来定位。它仍按隐藏层过滤选项决定是否导出。优先采用不含图层效果的内容边界；不支持时使用图层边界。空白图层无法确定中心点，会提示失败；请调整最底层图层或关闭开关。

关闭中心点选项时使用 PSD 已保存的标尺原点。该选项只改变工程的坐标基准，不会修改原 PSD，也不会新增动画。

## 使用官方标签

| 图层或组名 | 用途 |
| --- | --- |
| `head [bone]` | 创建骨骼，骨骼分组可嵌套 |
| `weapon [slot]` | 把图层放入指定插槽 |
| `outfit [skin]` | 创建皮肤 |
| `parts [folder]` | 将图片放入子目录 |
| `effects [merge]` | 把组内内容合成一张图片 |
| `reference [ignore]` | 跳过参考图层或分组 |

更多规则见[官方插件文档](https://github.com/EsotericSoftware/spine-scripts/tree/master/photoshop)。重复附件名需要调整图层命名或 skin / slot 分组。图层样式、蒙版、智能对象等复杂效果沿用官方插件的支持范围，应对自己的 PSD 进行目视核对。

## 处理失败

软件会记录失败信息，并继续处理后续文件。“完成当前后停止”会等待当前 PSD 完成，随后停止队列；不会强行结束 Photoshop。

| 现象 | 处理方式 |
| --- | --- |
| 没有找到 Spine | 点击“选择程序”指定 `Spine.com` 或 `Spine.exe` |
| Photoshop 导出失败 | 确认 Photoshop 可正常启动，关闭阻塞脚本的模态对话框，并检查图层名 |
| 工程生成失败 | 确认 Spine 已激活，且能运行 3.8.99；失败日志存入软件用户配置区 |
| 没有可导出图层 | 检查图层可见性、背景过滤和 `[ignore]` 标签 |
| 最底层为空 | 调整用于定位的最底层图层，或关闭中心点开关 |
| 拖入没有响应 | 确认文件类型受支持，且软件和资源管理器使用相同权限运行 |

失败任务的临时副本会被清理，不会覆盖已有工程。首次启动 Photoshop 或首次下载 Spine 指定版本可能需要较长时间。
